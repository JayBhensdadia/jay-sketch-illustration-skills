# Xiaohei IP

## Character Definition

Xiaohei (小黑) is the fixed visual IP for these sketch illustrations.

Every image should include Xiaohei by default. Xiaohei is not a mascot, not a sticker, not a cute decoration — Xiaohei is an absurd worker seriously participating in the operation of a system.

## Appearance

- Small solid creature, filled with the theme ink color (not hardcoded black).
  - Light theme: body filled with `--ink` (#1b1a17).
  - Dark theme: body filled with `--ink` (#ebe4d2).
- Eyes: two circular dots in the paper color (`--paper`), so they always contrast with the body.
  - Light theme: cream dots (#faf7f1) on a near-black body.
  - Dark theme: dark dots (#16140f) on a warm-cream body.
- Body shape can be cylindrical, bean-shaped, a rounded box, a funnel, a shadow, a hole opening, or a block inside a machine. Keep the silhouette consistent across a set of illustrations — don't change body shape mid-article.
- Outline slightly irregular, hand-drawn feel.
- Expression blank, dazed, calm, serious. Keep it consistent — no smiling, no expressive variation.

## Arms and Legs

Default limb spec (this is the fixed, consistent rule — don't vary it across images):

- **Arms**: Medium-weight strokes, thicker than hair-line detail but not tube-thick. Roughly 3× the weight of the fine line art — confident marker weight, not stick-thin.
- **Legs**: Same medium weight as arms. Two of them, short, slightly apart.
- **Hands**: Simple rounded nub at the end of each arm — not fingers, not a glove, just a clean rounded terminus the eye can read as a hand.
- **Contact with objects**: When Xiaohei touches, holds, pulls, or carries something, the arm must terminate cleanly against the object. Draw the hand-nub resting on, gripping, or overlapping the object — never leave a floating arm end that doesn't connect.
- **No fingers, no thumbs, no detailed hand anatomy.** The rounded nub is the hand.

## Personality

- Very serious, but doing something slightly absurd.
- Like a low-key system operator.
- Deadpan humor, doesn't play cute.
- A little clumsy, but not stupid.
- Like someone actually responsible for a task on a whiteboard sketch.

## Common Roles

Give Xiaohei the core action:

- Carrying raw materials.
- Pulling wires to gather information sources.
- Stuck at a breakpoint.
- Operating a "judgment" lever inside a machine.
- Becoming a sorting funnel.
- Cutting open the "material fish".
- Stamping a handoff script.
- Leading the handoff path.
- Holding a warning sign watching a pit.
- Reaching out from a hole but unable to catch the content.
- Off to the side: laying bricks, building bridges, opening doors, sorting, recording.

## Prohibitions

- Don't draw Xiaohei as an overly cute mascot.
- Don't draw as a children's cartoon character.
- Don't give Xiaohei complex costumes, emoji expressions, or sparkling eyes.
- Don't let Xiaohei just stand in a corner watching.
- Don't let Xiaohei overshadow the structural idea.
- Don't draw Xiaohei too commercial, too round, too polished.

## Quality Standard

If removing Xiaohei leaves the core metaphor completely intact, Xiaohei is too decorative — rewrite the prompt and make Xiaohei the action subject.
