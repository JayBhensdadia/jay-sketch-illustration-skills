# Composition Patterns & Originality Rules

## Base Structure Types

Pick one; don't mix too many.

### Workflow

Good for: input → processing → output, content production, AI workflows, automation pipelines.

How to draw: input on the left, Xiaohei or a strange machine processing in the middle, output on the right, sepia/amber arrows (#8a5a1f) showing main flow direction.

### System Detail

Good for: information sources, filters, databases, renderers, agent system internals.

How to draw: draw only 3–5 core modules; Xiaohei participates in one key action.

### Before-After

Good for: chaotic vs. ordered, manual vs. automated, scattered vs. gathered, anxious vs. stable.

How to draw: left side chaotic, right side stable, sepia/amber arrow in the middle. Characters can be more exaggerated.

### Character State

Good for: user pain points, creator states, too many tools, information anxiety, stuck vs. running.

How to draw: 2–4 small states, one short annotation per state.

### Conceptual Metaphor

Good for: content factory, information warehouse, mental black box, workflow machine, auto daily report.

How to draw: one large strange object or machine, sparse inputs, one output. Must have a memorable quality.

### Method Layers

Good for: methodology frameworks, system levels, skill stacks, content system layering.

How to draw: stacked boxes, not a formal pyramid; Xiaohei off to the side laying bricks or building.

### Map Path

Good for: idea to launch, user journey, content handoff path, learning route.

How to draw: one winding path, sparse nodes, Xiaohei pulling a line or walking.

### Comic Strip

Good for: failure to success, real process, commentary, before/after usage change.

How to draw: 2–4 small scenes; each panel expresses only one action.

## Original Metaphor Method

Invent a fresh metaphor from the current article every time — never copy an old image.

### Three Steps

1. Turn the abstract concept into a physical action: stuck, leaking, getting heavier, sorting, settling, fermenting, opening a door, folding, unpacking, flowing back.
2. Turn the system structure into a low-tech object: a broken machine, cardboard box, drawer, water pipe, mailbox, strange gauge, scale, well, ladder, odd workstation.
3. Give Xiaohei the action: not standing beside it — Xiaohei is stuck inside the machine, pulling the wrong wire, guarding the gate, carrying, patching, weighing, steadying the ladder, recording, stuffing something into a strange device.

### Object Pool

- Cardboard boxes, drawers, old machines, funnels, scales, mailboxes, doors, wells, ladders, pipes, tangles of wire, floodgates, turntables, black boxes, hole-punchers, noodle presses, clotheslines, odd workstations.
- Pick only 1–2 at a time; don't pile them up.

### Xiaohei Action Pool

- Pull, carry, stuff, scoop, press, weigh, sew, cut, twist, guard, push, receive, dismantle, label, recycle.
- The action must serve the core idea; don't be weird just to be weird.

## No-Copy Rules

Don't default to opening or replicating `assets/examples/`. Those images are for style calibration only — line density, white space, color restraint, Xiaohei's vibe.

Unless the user explicitly says "copy this one / replicate this composition / use this case as a base", never directly reuse these known compositions:

- Conveyor belt with two breakpoints
- Xiaohei inside a content machine pulling a judgment lever
- Xiaohei as a sorting funnel (flow / trust / conversion)
- Xiaohei cutting the material fish
- Xiaohei leading the handoff path
- Xiaohei pulling three layers of information sources
- Three Xiaoheis holding a megaphone / building a bridge / opening a door
- Xiaohei stamping the handoff-copy toolbox
- Xiaohei holding a sign watching the common-pitfalls path

Same-topic images must use a new metaphor. For example: "handoff path" doesn't have to be a road — it could be Xiaohei connecting a content tail to a door handle. "One fish, many uses" doesn't have to be a fish — it could be Xiaohei pressing one wad of paper into several shapes.
