# Prompt Examples

Copy any of these prompts directly into Codex.

## Planning only (no image generation)

```text
Use $jay-sketch-illustrations — do not generate images yet.
Analyze the article below and output a shot list of about 5 illustrations.
For each image specify:
- Which paragraph it follows
- Image theme
- Core idea
- Structure type
- What Xiaohei is doing
- Suggested elements
- Suggested annotation words

<paste article>
```

## Full article inline illustrations

```text
Use $jay-sketch-illustrations to generate 4 Xiaohei hand-drawn sketch illustrations for the article below.
Requirements: 16:9 horizontal, warm cream background (#faf7f1), near-black hand-drawn line art, sparse sepia/amber/muted-red/blue handwritten annotations.
Each image explains only one core structure — no PPT infographics, no cute cartoons.

<paste article>
```

## Illustration strategy for a long article

```text
Use $jay-sketch-illustrations to plan illustrations for this long article.
Don't distribute evenly — only pick cognitive anchors: core judgments, input-output loops, before-after contrasts, common pitfalls, handoff paths.
Default 6–8 images. Output shot list only; do not generate images yet.

<paste article>
```

## Generate a single-concept image

```text
Use $jay-sketch-illustrations to generate one 16:9 article illustration for this idea:

Trust isn't shouted — it's built one piece of evidence at a time.

Scene should be absurd but clean; Xiaohei must carry the core action.
At most 5 short annotations.
```

## Workflow topic

```text
Use $jay-sketch-illustrations to generate an image for "turning one raw piece of content into traffic, trust, and conversion".
Don't draw a formal flowchart; don't replicate the old one-fish-many-uses example.
Invent a new low-tech metaphor and give Xiaohei the core action.
```

## Edit: remove a title

```text
Use $jay-sketch-illustrations to edit this image.
Remove the "Workflow / Flowchart" title and underline in the top-left corner; keep everything else exactly the same.
Fill the removed area with the same warm cream background (#faf7f1). Do not add any new text or objects.
```

## Edit: strengthen Xiaohei's role

```text
Use $jay-sketch-illustrations — the direction of this image is right, but Xiaohei feels like decoration.
Keep the core idea intact and regenerate: make Xiaohei the one actually driving the structure.
Make the scene stranger, but still cream-background, clean, and sparse.
```

## Generate a style sample set

```text
Use $jay-sketch-illustrations to output 5 Xiaohei sketch illustrations on different themes.
Themes: information overload, product validation, content compounding, solo business, trust building.
Generate each one separately; do not combine into one image.
```
